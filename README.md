# EERI 2027 — GitHub Pages

Bu klasör GitHub Pages ile yayımlanmaya hazır statik site dosyalarını içerir.

## Yayınlama

1. `index.html`, `assets/` ve `.nojekyll` dosyalarını GitHub deposunun kök dizinine yükleyin.
2. Depoda **Settings → Pages → Build and deployment** bölümünü açın.
3. **Deploy from a branch** seçin; `main` dalı ve `/(root)` klasörünü belirleyip kaydedin.
4. GitHub Pages’in verdiği adresi kullanın.

Site görselleri `assets/` klasöründedir; klasör yapısını koruyun.
